# 云海工作台 · 使用手册（评测用知识库样本）

> 这份文档是第十阶段评测用的**样本知识库**之一。里面的内容刻意写成"可被问题精确命中"的事实条目，
> 用来衡量检索与阈值拦截的真实表现，不代表线上文案的最终版本。

## 一、产品定位

云海工作台是一个个人效率仪表板，把任务管理、数据可视化、天气、主题外观四件事收在一个页面里。
它基于 Vue 3、TypeScript、Tailwind CSS 与 Element Plus 构建，桌面版用 Tauri 2 打包，
前端在未登录时以「本地模式」完整可用，登录后通过 Supabase 做账号级数据同步。

## 二、任务模块

- 任务支持四个优先级：urgent、high、medium、low，默认是 medium。
- 任务可以设置截止日期、备注、所属标签；标签最多 12 个，每个标签有自己的主题色。
- 批量删除后会**一次性撤销全部**，撤销窗口是 5 秒。
- 「智能添加」用自然语言输入一句话即可生成任务草稿，草稿必须经过用户确认才会入库。
- 「AI 拆解」会把一个大目标拆成 3 到 6 条可执行子任务，子任务至少有一条是高优先级。

## 三、数据可视化

统计页固定在 `/stats`，提供本周、本月、全部三个时间范围，切换后即时重绘。
图表一共四张：标签占比环形图、7×24 完成时段热力图、趋势柱线混合图、投入产出散点图。
散点图的横轴是当日计薪时长，纵轴是当日完成数，并附上皮尔逊相关系数。
年度报告页在 `/annual`，用 canvas 自绘一张 720×1000 的分享卡，按设备像素比导出 2 倍图。

## 四、赚钱秒表与投入日志

秒表按小时薪资计算当前收益，支持迷你折叠模式。
投入日志按天记录计薪时长，写入规则有三条：
1. 只在秒表 tick 时**取较大值**写入，因此重复写入是幂等的；
2. 按整分钟节流，100 毫秒一次的 tick 不会每次都落盘；
3. 未配置薪资时不记录——没有薪资配置就没有依据推断作息。
日志按 400 天窗口加条数上限裁剪，避免本地存储无限膨胀。

## 五、账号级数据同步

同步在 `user_settings` 表里**一行一个 key**，主键是「用户 + 键名」，因此同一个设置项几乎不会冲突。
跟账号走的偏好一共 16 项，包括主题与外观、壁纸、标签、快捷导航、纪念日倒计时、发薪日、
仪表板卡片顺序与显隐、周目标、秒表配置、投入日志、提醒设置、默认搜索引擎。
刻意留在本机的有：AI Key、微信推送 UID、已通知标记、天气缓存、上次定位城市、侧边栏折叠状态。
壁纸图片本体存在 Supabase Storage 的 `user-assets` 桶里，公开读、只允许写入本人目录。

## 六、部署与运行

线上部署在自有服务器的 IIS 上，站点走 80 端口的 `/workspace/` 子路径，
子路由刷新不会 404（IIS 的 URL Rewrite 把未命中路径回落到 index.html）。
桌面版安装包命名是「云海工作台_0.1.0_x64-setup.exe」，绿色版直接是「云海工作台.exe」。
环境变量文件 `.env.local` 只在启动时读取，改完必须重启开发服务器才生效。

## 七、AI 能力的边界

工作台早期只做「嵌在动作里的 AI」：自然语言添加任务与目标拆解两条链路，走 BYOK（用户自带 Key），
Key 存在浏览器本地，请求由前端直连厂商接口。
第十阶段起新增知识库问答，Key 改由后端保管，前端只拿一个基地址。

## 八、快捷键与交互

- `Ctrl/Cmd + K` 打开聚合搜索。
- `Ctrl/Cmd + B` 折叠侧边栏。
- 主题切换按钮在顶栏右侧，支持浅色、深色、跟随系统三种模式。
- 移动端把底部导航固定为四项：仪表板、任务、统计、设置。

## 九、常见故障排查

- **深色模式下图表发白**：图表容器的背景色必须显式设为 transparent，由主题令牌控制坐标轴与网格颜色。
- **桌面版与浏览器数据不一致**：两者使用不同的用户数据目录，登录同一账号后以云端为准。
- **提醒重复弹出**：归档任务如果仍留在提醒列表里，会重复触发；提醒应基于包含归档的实时任务列表计算。
- **天气显示不出来**：检查高德 Key 是否申请了「Web 服务」类型的服务，类型选错会返回 infocode 10009。
